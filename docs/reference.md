# 用户与开发参考

本页是 External Amplifier HIL Kit 的操作与开发参考。数据契约的完整定义另见 `docs/*-json.md` 和 `docs/*.schema.json`。

## 应用启动

```sh
npm run dev
npm run build
npm start
npm run test:unit
npm run lint
```

未绑定 Gauge 项目时只显示启动页。项目目录必须包含 `manifest.json` 或 `.gauge`。

## 车型名规则

所有资产使用同一归一化函数：

```ts
normalizeVehicleName(raw) = raw.replace(/\s+/g, '').replace(/-/g, '_')
```

示例：

| 原始 | 归一化 |
| --- | --- |
| `FASLF 带华为智驾` | `FASLF带华为智驾` |
| `SFHAZ-18CH` | `SFHAZ_18CH` |
| `A / HT-FDLK` | `A`、`HT_FDLK` |

## 需求解析

- 需求 ID 和名称删除所有空白字符。
- 变体按 NFKC 归一后的 `key` 合并。
- `content` 保留原始变体描述，`vehicles` 合并去重。
- 空变体键表示该需求无变体差异。
- 需求映射参与状态保存在 `requirements.json.mapping`。

## 配置状态

| 层级 | 正常 | 浮空 | 异常 / 失效 |
| --- | --- | --- | --- |
| 关联变体 | 能找到需求变体 | 不适用 | 找不到对应变体 |
| 配置值 | 全部关联变体正常，或无关联但有特殊车型配置 | 无关联且无特殊车型配置 | 存在失效引用 |
| 配置项 | 所有配置值正常 | 存在浮空配置值或无配置值 | 存在异常配置值 |

配置项汇总优先级：`异常 > 浮空 > 正常`。

特殊车型规则：

| 类型 | 含义 |
| --- | --- |
| `starts_with` | 车型名称以参数开头 |
| `contains` | 车型名称包含参数 |

特殊规则命中 0 个车型仍算已配置，状态为正常。

## 规格条件

| 语法 | 含义 |
| --- | --- |
| `配置项-配置值` | 该配置值的生效车型 |
| `&` / `&&` | 交集 |
| `\|` / `\|\|` | 并集 |
| `!` / `~` | 相对车型全集的补集 |
| `(...)` | 改变优先级 |
| 空条件 | 全部车型 |
| 预留、不适用 | 空集合 |

求值顺序：`!` 高于 `&`，`&` 高于并集。

场景最终车型是规格书级条件和场景级条件的交集。

## 出声位置关键字

只识别步骤中的单双引号内容：

```markdown
* speak="左前低音|左前高音|中置"
* no_speak="右前低音|右后低音"
```

- `speak=`：出声扬声器关键字。
- `no_speak=`：不出声扬声器关键字。
- 未写适用车型表示全部车型。
- 旧竖线写法只作为普通步骤。

## SLOT 映射格式

```markdown
适用车型:SC6H/YU2
# 音源盒打开媒体音SLOT
* 音源盒打开SLOT1
* 音源盒打开SLOT2
```

- 首行 `适用车型:` 拆分车型。
- `#` 是音源场景。
- 步骤中的 `SLOT数字` 是通道。
- 连续 SLOT 显示为 `1-3`，非连续用 `、`。
- 无 SLOT 步骤显示为 `-`。

## 快照格式

```ini
[SC6H/HTHE_HTBU/SF海外]
左前低音
右前低音
```

- 每个 `[车型]` 是一个快照分节。
- 扬声器按非空行从通道 1 递增。
- 兼容 `通道N对应扬声器` 写法。

## 一键运行顺序

1. 导入需求。
2. 刷新配置并检查异常。
3. 更新场景车型 tags。
4. 重建出声位置目标 CPT。
5. 重建 SLOT 映射目标 CPT。
6. 更新 `env/<环境>/value.properties` 的 `vehicle_model`。
7. 执行 `gauge --tags <车型>`。

任一步失败会中止运行，并显示失败步骤。

## 任务与队列

| 类型 | 行为 |
| --- | --- |
| 任务 | 保存到 `.hil-kit/tasks.json`，可保存后运行 |
| 场景 | 运行单个场景，不保存任务 |
| 规格书 | 运行整份规格书或单个场景 |
| 测试队列 | 任务、场景、规格书按顺序执行，可继续入队 |

队列状态：等待、运行中、成功、失败。待执行项可排序、移除；点击名称可查看该项输出。

## 桌面安全约定

- 渲染进程只能通过 `window.desktop` 调用受控 IPC。
- spec、cpt、任务路径限制在项目 `specs` 内。
- Gauge 调用不经过 shell 拼接。
- 目录外路径和路径逃逸会被拒绝。
