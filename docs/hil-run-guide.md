# 一键多车型 HIL 测试运行指南

这是一篇**操作指南**，解决的问题是：从项目资产配置开始，输入一个目标车型，自动更新需求、配置、车型标签和目标 CPT，并执行 Gauge 用例。

## 前置条件

- 已通过启动页选择 Gauge 项目根目录。
- Gauge CLI 已安装，或已在「项目设置 → Gauge 运行」中指定可执行文件。
- 项目内已准备：
  - 需求分析表 Excel；
  - 出声位置文件、SLOT 映射目录、音量表、扬声器快照；
  - `specs/*.spec`；
  - 出声位置与 SLOT 映射的目标 CPT 文件。
- 车型命名统一，已按规则归一化：删除所有空白字符，`-` 改为 `_`。

## 1. 配置项目资产路径

打开标题栏齿轮按钮「项目设置」，填写：

| 设置项 | 作用 | 示例 |
| --- | --- | --- |
| 需求分析表 | 运行前自动导入最新需求 | `./config/关联需求/需求分析表.xlsx` |
| 需求数据 | 需求与变体落盘位置 | `./.hil-kit/requirements.json` |
| 配置参数 | 配置项/配置值落盘位置 | `./config/配置参数/config.json` |
| 出声位置文件 | 解析出声场景和扬声器关键字 | `./config/出声位置/出声位置.txt` |
| SLOT 映射目录 | 扫描目录下 `.txt` 映射方案 | `./config/SLOT映射` |
| 扬声器快照文件 | 解析 `[车型]` 分节 | `./config/扬声器快照/snapshot.ini` |
| 音量表文件 | 解析车型 × 音源 × 档位 | `./config/音量表/test.csv` |
| 出声位置目标CPT文件 | 运行前替换出声位置概念实现 | `./specs/concepts/出声位置.cpt` |
| SLOT映射目标CPT文件 | 运行前替换 SLOT 概念实现 | `./specs/concepts/SLOT映射.cpt` |
| Gauge 可执行文件 | 留空使用 PATH 中的 `gauge` | `gauge.exe` |
| 环境名 | 写入 `env/<环境>/value.properties` | `default` |
| 附加参数 | 插入 `gauge run` 与规格书路径之间 | `--verbose` |

路径支持相对项目根，保存时统一为 `./` 前缀。

## 2. 导入需求并检查配置

1. 打开「软件需求」，确认需求及变体已展示。
2. 对暂时不参与参数映射的需求，在「映射」列切换为「不参与」。该状态保存在 `requirements.json` 的 `mapping` 字段中。
3. 打开「配置参数」，为配置值关联需求变体，或填写特殊车型规则：
   - `车型名称以 xxx 开头`
   - `车型名称包含 xxx`
4. 检查状态：
   - 关联变体：`正常 / 失效`
   - 配置值：`正常 / 浮空 / 异常`
   - 配置项：`正常 / 浮空 / 异常`

若配置项或配置值为「异常」，一键运行会中止并列出异常配置键。

## 3. 维护场景资产

- 「出声位置」：按 `#` 场景、`适用车型:`、步骤中的 `speak=` / `no_speak=` 维护。
- 「SLOT 映射」：目录下每个 `.txt` 为一种映射方案，首行 `适用车型:`，`#` 为音源场景，步骤中的 `SLOT数字` 为通道。
- 「规格书」：场景使用 `适用条件` 引用 `配置项-配置值`，计算最终适用车型。

## 4. 选择任务类型与运行车型

可从以下入口执行：

| 入口 | 用途 | 运行车型 |
| --- | --- | --- |
| 新建任务 | 保存一组场景，并执行任务或单次场景 | 下拉选择 |
| 规格书 | 运行整份规格书或单个场景 | 下拉选择 |
| 测试队列 | 按顺序执行任务、场景、规格书 | 入队时记录每个队列项车型 |

## 5. 一键配置运行

在「新建任务」选择运行车型后点击「一键配置运行」。运行前会依次：

1. 导入最新需求；
2. 刷新配置并检查异常；
3. 更新场景车型 `tags`；
4. 重建出声位置目标 CPT；
5. 重建 SLOT 映射目标 CPT；
6. 更新 `env/<环境>/value.properties` 中的 `vehicle_model`；
7. 执行 `gauge --tags <车型>`。

示例环境变量：

```properties
vehicle_model = SC6ECU
```

示例执行命令形态：

```bash
gauge "run" "specs/example.spec" "--scenario" "Vowel counts in single word" "--tags" "SC6ECU"
```

## 预期结果

- 底部终端显示各配置步骤，包括需求导入数、CPT 写入路径、tags 更新结果。
- 生成后可查看：
  - 出声位置目标 CPT；
  - SLOT 映射目标 CPT；
  - `env/<环境>/value.properties` 中的 `vehicle_model`；
  - Gauge 命令输出、标准输出、错误输出和退出码。
- 指定车型时，Gauge 仅执行对应 `tags` 命中的场景。
- 任一配置步骤失败时，本次运行中止，不执行 Gauge。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 需求导入失败 | 检查「需求分析表」路径、工作表名和列映射是否有效。 |
| 配置存在异常 | 按页面提示修复失效引用或补齐配置值。 |
| 适用条件警告 | 打开规格书，检查条件引用是否为 `配置项-配置值` 且值存在。 |
| 目标 CPT 生成失败 | 确认目标路径是 `.cpt` 文件，且目标概念格式合法。 |
| Gauge 启动失败 | 检查可执行文件路径、附加参数和项目根目录。 |
| 运行车型为空 | 一键配置运行前必须选择运行车型。 |
| 未找到适用场景 | 检查场景 tags 是否已更新，以及车型归一化命名是否一致。 |
